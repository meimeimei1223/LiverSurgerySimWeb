# demo-vr-min-v1 — AE-CAI 会場デモ用の VR 最小操作版（凍結）

`https://meimeimei1223.github.io/LiverSurgerySimWeb/demo-vr-min-v1/`

Quest 3 専用。**装着して 10 秒で、説明なしに「引っ張る → 切る」が通る**ことだけを目的にした凍結
スナップショット。root（FULL、v325）のコピーに、会場向けの制限を加えたもの。**root には一切影響
しない**（`index.html` 冒頭の `const VRMIN = true;` を `false` にすると FULL と同じ挙動に戻る）。

慣れた人には root の FULL を案内する。スマホの来場者には `../?tut=1`（チュートリアル自動起動）。

## 操作

| 操作 | 割り当て |
|---|---|
| **右手 人差し指ピンチ** | 切る（ピンチで刃が出る → 動かして合わせる → 離した瞬間に実行） |
| **左手 人差し指ピンチ** | ハンドルを引っ張る |
| 中指ピンチ | **使わない**（両手とも） |

## FULL との違い

- **モード切替が無い**。起動時に Free Cut 固定、切る対象は肝臓固定（門脈・静脈は表示のみで切れない）
- **ハンドルは 3 点プリセット**。追加も削除もできない
- **カット後のフラグメント選択が出ない**。大きい方を自動採用（`sizeIndex` はテト数の降順なので
  rank 0 が常に最大）
- **肝臓は起動時から半透明**（60%）。血管が透けて見え、かつ切断面が読める値
- **パネルは正面に出ない**。右斜め後ろ（右 0.75m / 後ろ 0.25m / 下 0.15m、面は頭を向く）に置かれる。
  来場者の視野に入らないので誤ホバーしないが、説明員が振り向けば **Reset** に手が届く。
  パネルは縁を掴めば引き寄せられる

## リセット（説明員向け）

振り向いてパネルの **Reset** を 2 回押す（2 段階確認）。ページ再読込は Exit VR → リロード →
再入場で 20-30 秒かかるので、行列では使わない。

## 触っていないもの

- `drawPanelCanvas()`（445 行）と `panelHitTest()` — パネルは「描き換える」のではなく
  「置き場所を変える」で対処した。v324 の回帰はこの二重管理から出たため
- `firebase-loader.js` — root からそのままコピー（著者判断）

## 凍結

`sw.js` の `CACHE_NAME` は `liver-sim-demo-vr-min-v1`（root と既存の凍結 3 本のどれとも衝突しない）。
git tag `demo-vr-min-v1` で凍結。**更新しないこと** — 直す場合は別フォルダを切る。
